# 🎬 HyunsuFlix

**영화 메타데이터 기반 콘텐츠 추천 서비스**

*Content-Based Filtering으로 비슷한 영화 10개를 추천해드립니다*

</div>

---

## 📌 프로젝트 개요

사용자가 선택한 영화와 콘텐츠 기반(Content-Based Filtering) 유사도를 계산하여, 비슷한 영화 10개를 추천하는 머신러닝 기반 개인 프로젝트입니다. 영화 포스터 및 메타데이터는 TMDB API를 활용했으며, Streamlit을 이용해 간단한 웹 서비스 형태로 구현했습니다.

데이터 전처리부터 추천 알고리즘 구현, 웹 서비스 배포까지 전체 파이프라인을 혼자서 직접 설계하고 구현한 솔로 프로젝트입니다.

---

## ✨ 주요 기능

- **콘텐츠 기반 영화 추천**: 사용자가 선택한 영화와 유사한 영화 10개를 추천
- **영화 포스터 및 정보 불러오기**: TMDB API로 포스터, 제목, 개봉일 등 메타데이터 조회
- **웹 페이지 구현**: Streamlit 기반 웹 UI로 추천 결과를 시각적으로 확인

---

## 🛠️ 기술 스택

`Python` `Pandas` `NumPy` `Scikit-learn` `TMDB API` `Streamlit`

### 기술 스택 선정 이유

| 기술 | 선정 이유 |
|---|---|
| **Python** | 데이터 전처리부터 추천 알고리즘 구현, 웹 서비스 배포까지 하나의 언어로 통합 개발이 가능해 효율적 |
| **Pandas & NumPy** | 영화 데이터셋의 결측치 처리, 텍스트 병합, 벡터 연산 등에서 높은 성능과 편의성 제공 |
| **Scikit-learn** | 콘텐츠 기반 추천에 필요한 TF-IDF 벡터화와 Cosine Similarity 계산을 안정적으로 지원 |
| **TMDB API** | 포스터·제목·개봉일 등 신뢰할 수 있는 영화 메타데이터를 풍부하게 제공 |
| **Streamlit** | 추천 모델을 실제 서비스처럼 시각적으로 보여주면서도 빠르게 UI를 구성할 수 있어 개발 시간 단축 |

---

## ⚙️ 구현 핵심 기술

- 텍스트 기반 벡터화(TF-IDF / Count 기반) 비교 알고리즘 구현
- 영화 데이터셋 전처리, 결측치 처리, 텍스트 병합
- 영화 간 유사도 행렬(Cosine Similarity Matrix) 계산
- TMDB API 연동을 통한 포스터·제목·개봉일 출력 기능 개발
- Streamlit 기반 컴포넌트(UI) 구성 및 그리드 레이아웃 개발

## 🐛 트러블 슈팅

### TMDB 검색 결과 중복 문제

**문제**: 영화 제목만으로 TMDB API를 검색하면 동일한 제목을 가진 서로 다른 영화(리메이크작, 동명이인 작품 등)가 여러 개 검색되어, 사용자가 의도한 영화와 다른 포스터·메타데이터가 노출되는 문제가 있었습니다.

**해결**:
- 제목 기반 검색 대신 **TMDB ID 기반 검색 방식**으로 전환해 정확한 영화 데이터와 포스터만 가져오도록 개선했습니다.
- API 호출이 실패할 경우를 대비한 **fallback 처리 로직**을 추가해 UI가 깨지지 않고 안정적으로 동작하도록 보완했습니다.

## 📈 프로젝트 성과

- 콘텐츠 기반 추천 시스템의 전체 구조를 직접 구현하며 텍스트 기반 머신러닝 추천 알고리즘 전반을 이해할 수 있었습니다.
- 간단한 형태의 추천 모델을 Streamlit을 통해 웹 서비스로 배포하여 **데이터 분석 → 모델링 → 서비스 구현**까지 전체 파이프라인 경험을 쌓을 수 있었습니다.
